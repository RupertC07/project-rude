# Rude – Crypto Forecast Bot

**Rude** is a project that sends cryptocurrency forecasts to users via **Telegram** and **Discord**.

## ⚙️ Environment Variables (`.env`)

| Variable                       | Description |
|--------------------------------|-------------|
| `NODE_ENV`                     | Environment mode (`development` or `production`). |
| `PORT`                         | Port where the server runs (e.g., `8000`). |
| `DATABASE_URL`                 | MongoDB connection string (Atlas or local). |
| `DISCORD_CLIENT_ID`            | Discord bot Client ID from the [Discord Developer Portal](https://discord.com/developers/applications). |
| `DISCORD_CLIENT_SECRET`        | Discord bot Client Secret from the Developer Portal. |
| `DISCORD_CALLBACK_URL`         | Local OAuth2 callback URL for Discord. |
| `DISCORD_CALLBACK_URI_TUNNEL`  | Public tunnel URL for Discord OAuth2 callback (used when running locally but testing bot online). |
| `TELEGRAM_BOT_TOKEN`           | Telegram Bot API key from **BotFather**. |
| `JWT_SECRET`                   | Secret key for signing JWT tokens. |
| `TUNNEL_MODE`                  | Enables tunnel mode (`True` if testing locally with tunneling). |
| `PORT_FORWARD_URL`             | Public URL generated by tunnel service (e.g., DevTunnels). |
| `HOST_URL`                     | Base URL of your server (local or tunnel). |

> **Note:** Tunneling (e.g., via DevTunnels, ngrok) lets you expose your local server to the internet so bots can receive webhooks even if running on localhost.  
> All `.env` variables are loaded via `src/config/index.ts`.

## 🚀 Setup Instructions

### 1️⃣ Telegram Bot
1. Open Telegram and search for **BotFather**.
2. Create a new bot with `/newbot`.
3. Save the API key provided — set it in `.env` as `TELEGRAM_BOT_TOKEN`.

### 2️⃣ Discord Bot
1. Go to the [Discord Developer Portal](https://discord.com/developers/applications).
2. Create a new application.
3. In the **OAuth2** section, add your callback URLs:
   - Local: `http://localhost:8000/auth/discord/callback`
   - Tunnel: `https://<your-tunnel-url>/auth/discord/callback`
4. Copy your **Client ID** and **Client Secret** into `.env`.

### 3️⃣ MongoDB
- **Local**: Install MongoDB and use a connection string like `mongodb://localhost:27017/rude_db`.
- **Atlas**: Create a cluster at [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) and use the provided SRV URI.

### 4️⃣ Install & Run
```bash
npm install
npm run dev
```
This will start your server at `http://localhost:8000` (or your tunnel URL if enabled).
